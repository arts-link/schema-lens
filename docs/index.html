The overlay

Framework-free, accessible, isolated.

Rendered into a Shadow DOM host with its own styles, a resizable panel, keyboard focus handling and a polite live region. Nothing leaks into the page and the page’s JSON‑LD is never modified.

Summary, entities and scripts as three tabs Grouped by type, with per-entity findings and references Copy the whole inspection or a single entity as JSON Escape closes; focus returns where it was

Independent parsing

Every script is parsed on its own. One malformed script becomes a contained error instead of an empty result.

Exact @id linking

References resolve by exact string match. Unmatched absolute URLs are recorded as external rather than warned as unresolved.

Deterministic diagnostics

Unusable scripts are errors, likely data defects are warnings, hygiene and optional guidance is informational.

Mutation observation

Reacts to script insertion, removal, text changes and type attribute changes. It does not poll.

Four sources of information

Every finding carries a rule ID and a JSON path, so a parse failure never reads like an opinion.

1

JSON parsing errors

Empty, malformed, or an unsupported top-level value.

2

Structure and graph

Invalid @graph or identity fields, duplicates, ambiguous and unresolved links, value shapes.

3

Schema.org advisories

A small deterministic set for common types. Informational, not requirements.

4

Consumer rules

Your own checks, scoped to one entity or the whole result.

Register a project rule

const rules: InspectorRule[] = [
  {
    id: "project/article-section",
    scope: "entity",
    inspect({ entity }) {
      if (entity.types.includes("Article"))
        return [{ severity: "info", message: "…" }];
      return [];
    },
  },
];

inspectDocument(document, { rules });

Custom IDs cannot use the reserved schema-lens/ prefix. A rule exception becomes a contained diagnostic and does not stop other rules.

Watch the document

const observer = createSchemaObserver(
  document,
  (result) => {
    console.log(result.summary);
  },
  { debounceMs: 100 },
);

observer.refresh();
observer.disconnect();

Security and privacy

No runtime network requests are made. Schema data is never transmitted by the packages. Script text is parsed strictly with JSON.parse and never executed. Values render as text nodes, not injected HTML.
